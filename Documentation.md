# AI-Based Smart Complaint Management System
**B.Tech, 4th SEMESTER ESE EXAMINATION AIML (BLENDED) - AI308B**

## 1. Project Overview
This project is an end-to-end MERN Stack web application integrated with OpenRouter (Gemini API) to classify, summarize, and prioritize complaints. 

## 2. Code Quality & Folder Structure
```text
smart-complaint-system/
│
├── backend/
│   ├── controllers/      # Logic for API endpoints
│   ├── middleware/       # JWT Authentication middleware
│   ├── models/           # Mongoose schemas (User, Complaint)
│   ├── routes/           # Express API routes
│   ├── .env              # Environment Variables
│   └── server.js         # Entry point for backend
│
└── frontend/
    ├── src/
    │   ├── components/   # Reusable components (Navbar)
    │   ├── context/      # React Context for Auth state
    │   ├── pages/        # Views (Login, Signup, Dashboard, Submit)
    │   ├── App.jsx       # Main application routing
    │   └── index.css     # Premium UI styling and animations
    └── package.json
```
